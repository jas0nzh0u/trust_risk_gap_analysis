# Data

`survey_responses.csv` is deliberately not in this repository. It holds responses from real participants in a university research survey, and they consented to anonymised use in coursework and publication, not to a public data release.

To run the notebook with your own data, place a Microsoft Forms style export named `survey_responses.csv` in this folder. The notebook expects the same question columns as the original survey (age range, gender, academic background, platform usage, and trust and risk ratings for Snapchat, Facebook and WhatsApp). The column handling is described cell by cell in `notebook_explanation.txt`.
